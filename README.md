# Zhiwei v2.03

[中文](README.zh-CN.md) · [Install on Linux](docs/en/install.md) · [Release notes](docs/release-v2.03.md)

Zhiwei (知微) is a self-hosted, invitation-only web companion. Open a private conversation on your phone or desktop, send photos in order, quote a message, and return to the same conversation and its files later. Friends on the instance can also read and comment in a shared space. Private history and works stay associated with their recipient.

In v2.03 you can ask Zhiwei to draw, make a single-page website, create a layered design or build a simple 3D model. With the Linux offline browser installed, she can write an interactive page, click its controls, review screenshots and errors, revise it and deliver the downloadable HTML in chat. Download the example and open it locally to try the day/night control. [Window Reading example](examples/window-reading.html)

## Run your own instance

Use a Linux server with systemd, Node.js 24, a domain with HTTPS, and a Codex CLI account for model calls. Ubuntu 24.04 is the reference setup. Windows, macOS, iPhone and other modern browsers can connect as clients. Start with a fresh checkout and issue one invitation per friend. [Installation, first sign-in and offline browser](docs/en/install.md)

The template enables private memory and learning, photos, stickers, shared posts and creative tools. Automatic life planning and autonomous browsing start off. Site sign-in, video capture and notifications each have additional requirements. Model use consumes the allowance or billing of the configured account. The guided setup keeps the administration port on the host.

Running the earlier QQ release? Keep that installation and its data separately while testing the PWA. [Existing installation guidance](docs/en/install.md#existing-installations)
