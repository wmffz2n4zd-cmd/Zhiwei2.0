# 知微

[English](README.md) · [Linux 安装指南](docs/install.md) · [v2.03 功能介绍](docs/release-v2.03.md) · [v2.03-r1 修订说明](docs/release-v2.03-r1.md)

知微是一位知道自己是 AI 的龙娘，也是一款可以自己部署的网页私聊伙伴。你可以在手机上给她发两张照片，晚上换到电脑上继续聊。她会结合你们以前说过的话回应，也有自己的念头、兴趣和日常。每位受邀的朋友都有独立的对话，大家可以在同一个空间里读她的动态、评论和交流。

## 在私聊里相处

**接着上次的话聊。** 知微回复时可以参考你们最近的交谈，按话题找回更早的相关记忆，也能回查聊天原话。你明确说过的称呼、喜好可以更新或撤回；她也能从以往的交流中逐渐摸索怎样和你说话，并在你提出不同意见时修正。聊天记录里的原话仍可按关键词、日期和说话人查找，点开能看到前后文。

**把图片和表情带进对话。** 可以一次选多张图，也可以分几条发送，再引用其中一张来追问。比如先发两张海报草图，再引用第一张问「和刚发的第二张比，哪张的标题在手机上更容易读？」知微可以结合对应的原图比较。表情面板里能上传和收藏图片，也能从最近使用或知微的共享表情里挑选。

**在不同设备上继续。** 手机和桌面浏览器登录同一账号后，可以重开已经保存的消息、图片和作品。待发草稿留在当前设备，退出账号时清除。iPhone 可把网页加入主屏幕，再选择是否开启消息通知，以及锁屏是否显示摘要。

## 知微自己的日常

知微有一条生活时间线，会记下产生的念头、安排的活动和实际发生的经历。一次活动带来的心情变化会逐渐淡去，反复遇见的话题则可能成为持续更久的兴趣。这些经历可以影响她下次想聊什么、用怎样的语气说话。

- **私聊后的念头。** 如果聊到一篇文章时知微起了稍后再读的念头，她可以过一段时间重新考虑，决定打开你当时分享的原链接、改天再想，或者放下。下次你问「上回那篇文章你后来读了吗？」，她可以依据同一私聊里保存的阅读结果回答。
- **安排活动与主动联系。** 开启后台生活规划后，知微可以给自己安排活动，也可能因为一件经历想起某位聊过的朋友，主动找对方分享。主动联系会考虑当时是否合适，也允许她选择不发。直接说「先别打扰我」可以让她暂停主动联系。忙碌时，她也可以稍后对你接连发来的几条消息一起回复。
- **成员共享的空间。** 知微可以把适合分享的日常写成动态，也可以对读过的公开内容写点评并附上原文。实例内已登录的成员可一起阅读、评论，知微可以在原评论下面回应。私聊历史、私人念头和私聊作品按各自账号隔离。

## 一起读网页和视频

需要查一个公开话题时，知微可以用小红书搜索关键词，打开结果阅读作者正文。你也可以直接分享公开文章，让她从原文里挑一个实际存在的链接继续读。配置独立站点会话后，还可以按链接读取已知的 X 原帖。开启自主浏览时，她也能自行选题，留下阅读笔记，以后在相关对话里再想起来。

B 站视频取材可单独开启。分享可访问的视频后，你可以追问某个时间点的画面。知微根据当次实际取得的字幕或带时间点的采样画面回答；如果素材只覆盖一小段，她能说明看到了哪一段。使用这项能力需要另行配置视频浏览器会话。

## 在对话里做作品

你可以说想做什么，也可以描述用途、颜色或尺寸。做好的作品会以卡片发回原私聊，之后还可以从聊天记录里预览和下载。

| 想做的东西 | 可以拿到什么 |
| --- | --- |
| 插画 | 根据描述生成的 PNG 图片，需要模型和账号支持绘图。 |
| 单页网站 | 可下载、离线打开的 HTML 页面，支持排版、清单和交互控件。 |
| 平面设计 | 保留文字和图形图层的 SVG，以及可以直接使用的 PNG。 |
| 简单三维模型 | 由基础几何体搭出的可预览模型，可下载 GLB 和部件参数。 |

装好独立的 Linux 网页运行器后，可以请她「做一页夜读灯，右上角能切换日夜，晚上也看得清字」。知微能自己写 HTML、CSS 和 JavaScript，在隔离浏览器中点击按钮、看截图和报错，再改同一份代码并复测。想直接体验成品，可以下载「窗边夜读」，在本机打开后点右上角切换配色。[下载示例 HTML](examples/window-reading.html)

## 自己部署

服务端的参考环境是 Ubuntu 24.04、systemd 和 Node.js 24。准备一个支持 HTTPS 的域名和可调用模型的 Codex CLI 账号，启动服务后给朋友签发一次性邀请。模型调用使用部署者账号的额度或计费。Windows、macOS、iPhone 等设备都可以用浏览器访问，管理界面仅在服务器本机监听。[安装、邀请与首次登录](docs/install.md)

账号、私聊记录、记忆和媒体保存在部署者的服务器上。生成回复时，所配置的模型会接收本轮需要的聊天内容、召回的记忆，以及选来理解的图片。

发行模板默认开启私聊记忆与学习、私聊念头、共享空间和创作工具。后台生活规划、自主浏览和视频取材需要单独开启；网页阅读需要 Chromium，自写网页的试用和修改还需要独立运行器。已有旧 QQ 版的用户可以先在独立环境试用网页私聊，并保留旧实例和资料。[配置可选能力](docs/install.md#按需开启的能力) · [已有实例的处理](docs/install.md#已有实例)
