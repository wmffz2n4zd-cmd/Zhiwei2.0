# 知微 v2.03

[English](README.md) · [Linux 安装指南](docs/install.md) · [版本说明](docs/release-v2.03.md)

知微是可以自行部署、凭邀请注册的网页私聊伙伴。你可以在手机或电脑上和她聊天、按顺序发几张照片、引用消息，之后再从同一个账号找回聊天和作品。实例内的朋友还可以到共享空间看动态、发表评论。私聊记录和作品按接收账号隔离。

v2.03 支持绘图、交互单页、分层设计和简单三维建模。装好 Linux 离线浏览器后，你可以请知微自己写一页网页、点按钮、看截图和报错，再修改并把成品发回原私聊。下载示例 HTML，在本机打开就能试它的日夜切换。[「窗边夜读」示例](examples/window-reading.html)

## 自己部署

服务端需要带 systemd 的 Linux、Node.js 24、支持 HTTPS 的域名，以及能调用模型的 Codex CLI 账号。参考环境为 Ubuntu 24.04。Windows、macOS、iPhone 等设备可以作为浏览器客户端。从独立目录安装，启动后给每位朋友签发一份邀请。[安装、首次登录与离线运行器](docs/install.md)

发行模板默认开启私聊记忆与学习、图片、表情、共享空间和创作工具。自动生活规划和自主浏览初始关闭。网站登录、视频取材和通知各有额外条件。模型调用使用部署者账号的额度或计费，管理端口只在本机监听。

已有旧 QQ 版的用户可以先在独立环境试用网页私聊，保留旧实例及其资料。[已有实例的处理](docs/install.md#已有实例)
