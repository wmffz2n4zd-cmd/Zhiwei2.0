# 表情包目录

把她会用的表情放进这个目录即可，支持 `.png` / `.jpg` / `.jpeg` / `.gif` / `.webp`。

- 文件名就是表情名。人格提示里按情绪（无语 / 笑死 / 难过 / 惊愕 / 愤怒 / 害羞 / 疑惑 / 得意 / 困困 / 收到）挑选，选中的名字会写进回复标记 `[[qq_sticker:文件名不含扩展名]]`，由发送端换成真实图片。
- 没有贴切表情时只发文字；只有一个表情也不会让文字消失（先发文字，成功后再单独发图）。
- 命名建议与情绪一致，例如 `笑死.png`、`无语.jpg`。同名不同扩展名会随机取一个。

**不要提交第三方有版权的表情图。** 这个目录默认是空的，`.gitignore` 只保留本文件。
