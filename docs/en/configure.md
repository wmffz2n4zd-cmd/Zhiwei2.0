# Configuration

> 中文: [docs/configure.md](../configure.md)

The main configuration is `data/local.json` (permissions should be 600), generated by `npm run setup`. Restart the service after changing it:

```bash
sudo systemctl restart zhiwei
```

`data/settings.json` is another layer of state, writable from the console; it normally does not need hand editing.

> Historical compatibility: if only `data/windows.local.json` exists, the program still reads it. Setup refuses by default to create a new file that would shadow it. Explicit `--force` permits a new preferred `local.json` while preserving the legacy file, but does not migrate its custom settings; review those first. New deployments use `data/local.json`. `ZHIWEI_CONFIG=/absolute/path/xxx.json` can select another configuration file.

---

## 1. Account and bridge

| Key | Type | Description |
| --- | --- | --- |
| `ownerUserIds` | string[] | Admin QQ numbers. **Only private chats from these numbers** get a response (unless `allowOtherPrivateChats` is turned on as well). |
| `botUserId` | string | Bot QQ number, used only for records and self-check hints. |
| `allowOtherPrivateChats` | boolean | Defaults to `false`. Once set to `true`, private chats from any stranger get a response, and are written into their own memory and profile. **Not recommended**. |
| `qqPrivateOnly` | boolean | Always `true` inside the program; group messages are dropped before they reach the model, and the send path also blocks the group APIs. This key does not accept "off". |
| `qqEnabled` | boolean | Whether the QQ channel is enabled at startup. After it is turned off, `/开启QQ` can still turn it on. |
| `oneBotApiBase` | string | NapCat's HTTP API address, default `http://127.0.0.1:3000`. |
| `oneBotSecret` | string | Callback signing secret (HMAC-SHA1). Matches the Token of NapCat's "HTTP Client". |
| `oneBotAccessToken` | string | Bearer Token for calling NapCat's send APIs. Matches the Token of the "HTTP Server". |
| `qqImageCacheRoots` | string[] | Allowlist of actual QQ/NapCat image-cache directories. Generate it with repeated `setup --qq-image-cache-root /directory` options. Empty means image/static-sticker vision is unavailable; text chat still works. Directories must be readable by the service user; do not allow an entire disk |

Both secrets must be generated by `npm run setup` and are **different for every instance**; do not copy someone else's configuration.

## 2. Model

| Key | Default | Description |
| --- | --- | --- |
| `chatModel` | empty | Model name for ordinary private chats; leave it empty to use the Codex default model. |
| `chatReasoningEffort` | `low` | `low` / `medium` / `high` / `xhigh`. |
| `privateChatModel` | empty | Overrides `chatModel` (higher priority, leave it out if you do not need it). |
| `privateChatReasoningEffort` | empty | Overrides the reasoning effort. |
| `remoteModel` | empty | Model used for `/执行` tasks. |
| `codexProxy` | empty | HTTP proxy for the Codex subprocess, for example `http://127.0.0.1:7890`. Leave it empty to connect directly. |
| `runtimeBudget.mode` | `observe` | See section 6. |

The model must be a name your account can use after `codex login`. A wrong name does not crash, but every generation fails and returns one local notice.

## 3. Life timeline

| Key | Default | Description |
| --- | --- | --- |
| `life.enabled` | `true` | Master switch. When off, there are no thoughts, schedule, mood progression, or proactive contact. |
| `life.planning.enabled` | `true` | Whether the model plans a day. **It reuses the restricted model entry point of `world`, so it requires `world.enabled=true`**; otherwise startup reports an error and exits. |
| `life.tickIntervalMs` | `15000` | Timeline advance interval, clamped to 250–15000. |

Do not raise `tickIntervalMs` just to make things "look quiet": an activity whose observation gap exceeds 2 minutes is judged an interruption.

## 4. Web reading

| Key | Default | Description |
| --- | --- | --- |
| `world.enabled` | `true` | Life planning depends on it; do not turn it off. |
| `world.executablePath` | empty | Chromium/Chrome executable. **When empty, reading fails, but planning and chatting are unaffected.** |
| `world.channel` | `chromium` | Playwright channel name; set it to `chrome` when using the system Chrome. |
| `world.headless` | `true` | Keep it `true` on a server. |
| `world.autoEnabled` | `false` | The old "browse autonomously every 4 hours" timer. **It does not start while life planning is enabled**, and browsing is triggered by activities in the timeline instead. |
| `world.maxSteps` | `4` | Maximum number of pages opened in one reading. |
| `world.proxy` | empty | Proxy for the browser only; if not filled in, `codexProxy` is used. |
| `world.xBrowser` | none | A separate browser configuration for X (its own login directory). Normally it is not written by hand. |

Logging in: the first time the browser opens a site it needs a human QR scan / SMS, and `data/world/browser-profile/` keeps the session (**this directory is sensitive data**). Without a login state, the page is judged a login page and its body is cleared, so a verification-code page is never fed to the model.

## 5. Persona

The single source of truth is `config/zhiwei-profile.md`, and the whole text is re-read on every reply generation (no restart needed for it to take effect). To switch to a character of your own:

```bash
cp config/zhiwei-profile.md config/my-persona.md
# edit config/my-persona.md
```

Then change it in `data/local.json`:

```json
{ "assistantProfile": "config/my-persona.md" }
```

Or override it with an environment variable (highest priority):

```bash
export CODEX_REMOTE_CONTACT_ASSISTANT_PROFILE_PATH=/srv/my-persona.md
```

Note: **a file that is configured explicitly but cannot be read is a hard error**; the program will not quietly swap back to the default persona. Only an empty string means "do not use a persona file".

## 6. Usage allowance and budget

| Mode | Behavior |
| --- | --- |
| `observe` (default, recommended) | Only writes the purpose, result, and available tokens of each model call into `data/runtime-usage/`, and **blocks nothing**. The life planning call cap and the browser daily quota are disabled as well. |
| `strict` | Reserves conservatively against the weekly limit (75% of 80%), and needs a manually calibrated record; otherwise every call is rejected. |

`observe` does not mean free or unlimited: the usage allowance is still consumed on your own account, the server simply does not throttle it. Check usage with `node scripts/runtime-usage.mjs inspect --from 2026-11-01 --to 2026-11-07`.

## 7. Tasks and extensions

| Key | Description |
| --- | --- |
| `workspace` | Default working directory for `/执行` tasks. |
| `remoteEnabled` | Whether `/执行` is allowed. |
| `allowFullAccessTasks` | Whether `/执行完全访问` (`danger-full-access`) is allowed. Defaults to `false`; before turning it on, read `../security.md`. |
| `skills` | `{"name": "/absolute/path/SKILL.md"}`, used for `/技能`. |
| `chatSkill` | Which Skill ordinary chat uses by default; `none` means none is used. |
| `automationScripts` | Allowlist for `/运行脚本 <name>`: `{"name": {"command": "...", "args": [...], "timeoutMs": 30000}}`. Only fixed commands are executed; argument concatenation is not accepted. |
| `desktopRecall` | Meaningful only on macOS; on Linux keep `enabled:false`. |

## 8. Environment variables

| Variable | Effect |
| --- | --- |
| `PORT` | Hub port, default 3789 (binds 127.0.0.1 only). |
| `ZHIWEI_CONFIG` | Specifies the configuration file path. |
| `CODEX_CLI_PATH` | Specifies the Codex executable. |
| `CODEX_HOME` | Codex configuration directory, default `~/.codex`. |
| `ONEBOT_API_BASE` / `ONEBOT_SECRET` / `ONEBOT_ACCESS_TOKEN` | Override the same-named entries in the configuration file. |
| `CODEX_REMOTE_CONTACT_ASSISTANT_PROFILE_PATH` | Overrides the persona file path. |
| `TZ` | Service time zone, `Asia/Shanghai` recommended; the life timeline starts a new day on Beijing time. |

systemd does not inherit an interactive shell's PATH. If customization is needed, copy `deploy/zhiwei.env.example` to `deploy/zhiwei.env` and set actual `CODEX_CLI_PATH`, `CODEX_HOME` and `PATH` values using absolute paths and mode600. The default unit optionally loads this file; `render-unit.mjs --service-env-file /absolute/path` selects another location. Log in to the CLI as the actual service user with the same HOME/CODEX_HOME. This file does not log in or copy credentials.

## 9. Common consequences of a broken configuration

| Symptom | Cause |
| --- | --- |
| Exits immediately at startup with "生活规划需要启用world" | `life.planning.enabled=true` but `world.enabled!=true`. |
| All callbacks return 401 | `oneBotSecret` does not match the NapCat client Token. |
| Messages arrive but get no reply | The model name is unavailable, Codex is not logged in, or you are not in `ownerUserIds`. |
| Replies with a single "额度受限" | `runtimeBudget.mode` is `strict` and there is no calibration record. |
| The life page stays blank | `life.enabled` is off, or no event exists yet (a blank page is a normal, allowed state). |
