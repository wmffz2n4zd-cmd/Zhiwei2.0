# 发行审查记录

> English: [docs/en/release-audit.md](en/release-audit.md)

本文件是**脱敏后的**发行审查摘要：只描述类别、范围和结果，不包含任何真实账号、地址或路径的对应关系。逐文件的敏感映射保存在维护者的私有工作记录里，不随发行版分发。

第1—2节保留DSH对初始发行树与压缩包的历史审查摘要；统计不自动覆盖后续修改。当前发行树的精确文件清单以 `MANIFEST.sha256` 为准，验证状态见[验收记录](verification.md)及对应CI提交。

## 1. 历史来源与提取

- 来源是一个已上线的私有部署实例的源码快照，按**显式白名单**提取，不是整仓复制。
- 提取时逐个文件比对来源清单的 SHA-256 与字节数；提取后再比对一次写入结果。
- 提取结果：108 个文件与来源逐字节一致，7 个文件做了发行适配，其余为发行版新增（含英文文档）。
- 适配只涉及：配置文件路径兼容、启动自检、包名与脚本入口、控制台页面链接与文案、体检脚本。
- 工程记录、部署工具链、真实模型评估脚本、运行数据、备份与日志**全部排除**。

- 未验证 ARM、Windows、macOS。

## 5. 复核方式

任何人可以独立复核：

```bash

grep -rn "TODO\|FIXME" src/ | head    # 自行检查遗留标记
node --test tests/*.test.mjs          # 运行自带测试
```
