# 知微 v2.03

知微现在通过邀请制网页私聊。你可以从手机连续发几张照片，引用旧图追问，也可以到空间看她的动态、发表评论。私聊里的照片、历史和作品按账号授权，空间里的动态和评论由已登录成员共读。

这版加入了绘图、单页网站、平面设计和简单 3D 建模。制作交互网页时，知微可以自己写 HTML、CSS 和 JavaScript，在独立浏览器里点击按钮，查看截图和错误，修改并复测，再把可离线打开的文件发回原私聊。发行包的 `examples/window-reading.html` 是一件验收作品，下载后打开，点击右上角即可切换日夜配色。

自托管请从 `README.zh-CN.md` 和 `docs/install.md` 开始。旧版 QQ 自托管用户应在独立目录安装，并保留原实例及资料备份。离线试用自写网页需要安装随附的 Linux systemd 运行器。

## English

Zhiwei now runs as an invitation-only chat PWA. Compare photos across messages, quote earlier images and talk about them, or visit the members' space to read and comment on posts. Chat history, photos and downloadable creations are scoped to their owner.

The creative tools produce drawings, single-page websites, graphic designs and simple 3D models. With the Linux browser worker installed, Zhiwei can write a page, click its controls, inspect screenshots and errors, revise the code and deliver a standalone HTML file in the original conversation. Open `examples/window-reading.html` offline and use the button in the top right to switch between its day and night themes.

For a fresh deployment, see `README.md` and `docs/en/install.md`. Install alongside an older QQ deployment in a separate directory and retain its data and backup.
