# 知微 v2.03-r1

这是 v2.03 的 GitHub 发行修订。全新 Ubuntu 安装检查按项目锁定的 Playwright 版本安装配套 Chromium，自托管用户依照安装指南会用到同一版浏览器。发布检查通过独立的 systemd 运行器打开示例网页，两次点击日夜切换按钮，核对页面文字和三张截图。[中文安装指南](https://github.com/wmffz2n4zd-cmd/Zhiwei2.0/blob/v2.03-r1/docs/install.md) · [v2.03 原版发行说明](https://github.com/wmffz2n4zd-cmd/Zhiwei2.0/releases/tag/v2.03)

## English

This packaging revision updates the GitHub clean-install check for v2.03. A fresh Ubuntu runner installs the Chromium build matched to the locked Playwright version, just as a self-hosted installation does. The release check uses the isolated systemd worker to open a sample page, click its day/night toggle twice and verify the text and three screenshots. [Installation guide](https://github.com/wmffz2n4zd-cmd/Zhiwei2.0/blob/v2.03-r1/docs/en/install.md) · [Original v2.03 release](https://github.com/wmffz2n4zd-cmd/Zhiwei2.0/releases/tag/v2.03)
